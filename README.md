# sing-box-sub-store-template

本仓库是 [xream/scripts](https://github.com/xream/scripts) 中 [sing-box/template.js](https://github.com/xream/scripts/blob/main/surge/modules/sub-store-scripts/sing-box/template.js) 的单文件 fork，保留原版脚本作为后续修改的起点。

[`template.js`](./template.js) 在 Sub-Store 的「文件管理 → 脚本操作」中运行。它读取订阅，将节点写入 sing-box 配置，并按规则把节点加入模板中已有的策略组。
